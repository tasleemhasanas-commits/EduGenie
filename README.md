# EduGenie – Google Gemini Powered Learning Assistant

## Project Overview

EduGenie is an AI-powered learning assistant designed to help students learn concepts easily and interactively using Google Gemini.

## Features

- Ask educational questions and get AI-generated answers
- Explain difficult topics in simple language
- Generate quizzes for learning and practice
- Summarize educational text
- Recommend personalized learning paths

## Technologies Used

- Python
- FastAPI
- Google Gemini API
- HTML
- CSS
- JavaScript
- Uvicorn
