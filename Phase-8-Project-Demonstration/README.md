# Phase 8 – Project Demonstration

## 1. Project Name

EduGenie – Google Gemini Powered Learning Assistant

## 2. Purpose

EduGenie is an AI-powered learning assistant designed to help students learn concepts easily and interactively.

## 3. Demonstration Flow

The demonstration will show:

1. Opening the EduGenie web application
2. Asking an educational question
3. Getting an AI-generated answer
4. Explaining a difficult concept
5. Generating a quiz
6. Summarizing educational text
7. Generating a personalized learning path
8. Showing the final results

## 4. Benefits

- Interactive learning
- Quick AI-generated responses
- Simple concept explanations
- Quiz-based practice
- Personalized learning support

## 5. Demo Video

A screen-recorded demonstration with voice-over will show the project name, purpose, working process, features, and final output.

## 6. Final Output

EduGenie provides an interactive AI-based learning experience through a web interface powered by Google Gemini and FastAPI.
