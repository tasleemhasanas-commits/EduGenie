# Phase 1 – Brainstorming & Ideation

## Project Name
EduGenie – Google Gemini Powered Learning Assistant

## Problem Statement
Students often face difficulty understanding complex educational concepts and finding personalized learning support.

## Proposed Solution
EduGenie is an AI-powered learning assistant that uses Google Gemini to provide educational answers, simple explanations, quizzes, summaries, and personalized learning paths.

## Key Features

1. Ask educational questions
2. Explain concepts in simple language
3. Generate quizzes
4. Summarize educational text
5. Recommend personalized learning paths

## Target Users
- School students
- College students
- Learners preparing for exams
- Students who need quick concept explanations

## Benefits
- Simple and interactive learning
- Quick AI-generated responses
- Personalized learning support
- Helps students practice through quizzes
- Saves time when studying

## Technology Idea
The project uses Python, FastAPI, HTML, CSS, JavaScript, and Google Gemini API.

## Expected Outcome
A web-based AI learning assistant that helps students understand topics, practice questions, summarize content, and follow a structured learning path.
